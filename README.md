## Use it locally

Click **"Use this template"** on GitHub or clone the repository:

```sh
git clone https://github.com/tabler/tabler-starter.git
cd tabler-starter
npm install
npm run dev
```

Then open the printed localhost URL and edit `index.html`. Tabler's CSS and JavaScript are loaded from the CDN, so there is nothing else to configure.
